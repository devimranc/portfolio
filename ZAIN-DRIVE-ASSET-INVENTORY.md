## How folders were mapped

These folders contain more than one kind of work. The whole folder is listed once, under the closest category.

3D model is kept whole under 3D Modeling & Character Modeling, including 2D to 3D toy_ and Toy animation.mp4. The folder also holds product, vehicle, prop, and clothing stills. Book and camera stills from it remain on the separate product-stills page.

Rachel Rig is character rigs (idle, cop, female, male). The Work page publishes those clips as Unreal Engine integration, and the category Unreal Engine & VR is the closer published home for this folder. Gun rig Unreal stays inside Rigging Stuff, and Unreal Demo with CGI_ stays inside Character Animation2, because those parents are rigging and character animation.

Environment includes buildings, streets, and game environments, plus a 2D pixel-art set and a logo clip. The stills are environment and architecture work, so the folder is under Architectural Visualization. Architectural Game assets are low-poly and medieval building stills, so they are under Architectural Visualization. Waterfall is two environment clips and is under the same category.

Game assets_ is still images for a mystery-game set, Revenants Soul_, and a strategy-card UI. The Work page files game-art stills under 2D Animation & Motion Design, so this folder is there. Mascot is a still and a graphic-work PDF, so it is there as well. Web Based is a single shoe-model clip, under Product Modeling & Visualization. Stadium unity work includes an Unreal Editor recording, so it is under Unreal Engine.

No folder in this drive is an AI set. AI-Assisted Video & Animation is an existing Work page category and is empty here. Showreel and Stinkin_Awesome_4K-001.mp4 do not name a discipline, so they are unmapped rather than placed in a category.
